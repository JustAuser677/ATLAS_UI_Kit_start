## Схема primitive -> semantic -> component

Реальные цепочки светлой темы:

| Примитив | Семантическая роль | Компонентный токен | Применение |
|---|---|---|---|
| `--base-blue-700: #1853a4` | `--color-primary` | `--button-bg-primary` | `background` у `.button--primary` |
| `--base-white: #fff` | `--color-on-primary` | `--button-text-primary` | `color` у `.button--primary` |
| `--base-slate-950: #142338` | `--color-text` | `--control-text` | `color` у `.input` и `.select` |
| `--base-white: #fff` | `--color-surface` | `--control-bg` | `background` у `.input` и `.select` |

## Проверки

| Условие | Результат |
|---|---|
| 320, 375, 768, 1024, 1440 px | Проверены все четыре сочетания `light/dark ordinary/compact`: в 20 вариантах горизонтального переполнения нет |
| Длинное предупреждение на 320 px | Длинный текст и непрерывный идентификатор переносятся без увеличения ширины страницы |
| `auto`, `light`, `dark` при светлой и тёмной настройке ОС | Все шесть сочетаний дают ожидаемую палитру; ручной выбор имеет приоритет |
| Изменение системной темы в режиме `auto` | Палитра меняется без перезагрузки; атрибут `data-theme` отсутствует |
| Обычная и компактная плотность | Высота кнопки и поля меняется с 44 до 36 px |
| Независимость настроек | Изменение темы сохраняет плотность; изменение плотности сохраняет тему |
| Перезагрузка страницы | Тема и плотность восстановлены из отдельных ключей хранилища |
| Неизвестные значения в хранилище | Применяются `auto` и `ordinary` |
| Недоступный `localStorage` | Ошибок JavaScript нет; тема и плотность продолжают переключаться |
| Tab и Shift+Tab | У восьми доступных интерактивных элементов виден фокус 3 px; обратный переход работает |
| Hover и active у трёх вариантов кнопки в обеих темах | Фоны default, hover и active различаются |
| Кнопка с `disabled` | Нативно недоступна; применены `opacity: .55` и `cursor: not-allowed` |
 |
| Временное изменение `--color-primary` в браузере | Одновременно изменились кнопка, логотип и образец цвета; после проверки значение восстановлено |
| Контраст проверенных текстовых пар | Минимум **4,68:1**, что выше ориентира 4,5:1 |
| Контраст границ полей и заливки основной кнопки относительно окружения | Минимум **3,02:1**, что выше ориентира 3:1 |
| Демонстрационная кнопка | После нажатия появляется текст «Выполнено!» |
| Ошибки JavaScript и прямые HEX в компонентах | Ошибок не обнаружено; HEX-значения в правилах компонентов отсутствуют |
